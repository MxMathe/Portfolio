MEUS PROJETOS

App Confeitaria
Em Manutenção

Desenvolvido em Java direcionado para uma confeitaria, o app permite que clientes visualizem produtos, façam pedidos e acompanhem o processo, enquanto a loja pode gerenciar os pedidos recebidos. Conta com sistema de login para clientes e lojistas, cardápio com navegação simples e integração das funções principais em uma interface intuitiva. O projeto está em manutenção e em constante aprimoramento para oferecer uma melhor experiência aos usuários.

Dash Controle Financeiro
Em Melhoria

Desenvolvido um dashboard de controle financeiro em React com TypeScript, voltado para uso em farmácia. A ferramenta permite o acompanhamento diário de vendas, gastos e comissões, além de oferecer um resumo financeiro mensal. Com uma interface clara e responsiva, o sistema facilita a visualização de dados em tempo real, auxiliando na tomada de decisões e no controle eficiente do caixa. O projeto foca na organização e agilidade no gerenciamento financeiro do negócio.

Jogo Desafio Matematica
Em processo de melhorias

Desenvolvido um jogo educativo de matemática para que crianças testem seus conhecimentos, utilizando HTML, CSS e JavaScript o jogo oferece diferentes níveis de dificuldade com operações como adição, subtração e desafios mistos, estimulando o raciocínio lógico de forma divertida. Conta com animações, mensagens interativas, sistema de pontuação e uma tela de resultados com feedback final, tornando a experiência mais envolvente e motivadora. O projeto foi pensado para unir aprendizado e entretenimento em uma interface simples e acessível.
